# 3D scene assets: credits and licenses

All files in this folder come from [Poly Haven](https://polyhaven.com) or [ambientCG](https://ambientcg.com)
and are released under **CC0 1.0 (public domain)**: free for any use, no attribution required.
Credits are listed anyway.
They were downloaded on 2026-11-20 at 1K resolution and recompressed for size
(color and normal maps at 1024 px, ARM maps at 512 px).

Map suffixes: `diff` = base color, `nor` = normal (OpenGL convention), `arm` = ambient occlusion (R),
roughness (G), metalness (B). For Grass 004 the ARM map was assembled from ambientCG's separate
AmbientOcclusion and Roughness maps (metalness 0).

## Models (`models/`)

| File | Content | Origin and license |
|---|---|---|
| `models/argus_bike.glb` | "Argus Aero" road bike: carbon frame and fork, 45 mm carbon wheels, 50/34 crankset, 11-30 cassette, chain, derailleurs, disc brakes, cockpit, saddle, bottle | Original design, generated by `tools/blender/argus_bike/build_bike.py` (GPL-3.0-or-later, this project). Procedural textures (carbon weave, rotor, bar tape) generated by the same script. |
| `models/argus_rider.glb` | Rigged cyclist (53-bone "game_engine" skeleton) with Argus kit, shoes, helmet and glasses | Body, skin texture, eyes, eyebrows and hair from the **MakeHuman system assets, CC0 1.0** (Data Collection AB, Joel Palmius, Jonas Hauquier; http://www.makehumancommunity.org), assembled with **MPFB** (MakeHuman Plugin for Blender, GPL-3.0; used as a tool only). Kit texture, shoes, helmet and glasses generated by `tools/blender/argus_rider/build_rider.py` (GPL-3.0-or-later, this project). |

Both files are rebuilt with the scripts above (see `tools/blender/README.md`); no proprietary or
extracted assets are used.

Everything else in the scene (procedural fallback rider/bike, time-trial bike, trees, rocks, gates)
is generated in code at runtime.
